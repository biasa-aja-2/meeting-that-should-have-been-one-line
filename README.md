An entry for [The Meeting That Should Have Been One Line](https://make.fun/competitions/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c) on make.fun.

The task: write the single sentence that could have replaced an entire pointless meeting. No context, no explanation — just the line that kills the meeting and makes anyone who has sat through one laugh.

## The line

> The decision was made before the invite went out; this meeting is just the group photo.

The decision is already made, so there is nothing left to meet about — everyone in the room is only there to be seen attending, like posing for a group photo. Pure stdlib Python; `main.py` writes the line to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`), with a self-check gate (1–200 characters, single line, not whitespace-only) and a read-back verification.

## Run

```sh
python3 main.py
```
